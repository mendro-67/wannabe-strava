# Stride

A first-version running dashboard for tracking runs, seeing your weekly progress, and building a little consistency.

## Run it

Open `index.html` in a modern browser. No install or build step is required.

Your runs are saved in your browser with local storage. The dashboard starts with sample runs so you can explore the charts and activity list; log a run to add your own.

## What’s here

- A weekly summary for distance, moving time, and average pace
- A week/month distance chart and a 20 km weekly goal
- Recent activities, with an option to view your full history
- A run logging form for distance, duration, elevation, date, and an optional note
- Responsive layout for desktop and mobile screens
